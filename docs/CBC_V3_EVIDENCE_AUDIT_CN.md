# CaVER CBC v3：根据上传实验结果进行的证据审计与研究决策

**研究状态：2026-11-05；输入：本轮上传的 `CaVER_CBC_report_bundle.zip`、`CaVER_CBC_revised_2026-11-05(1).zip`、`interactive planning(3).tex`。**

## 0. 必须首先区分的三项命题

- **H1：存在性。** 两个在规划时刻预定义且同意图的 Ego 轨迹，可能通过异质反应延迟改变非 Ego 的二次碰撞/恢复结局。合成结构仿真提供了内部存在性证据，不能推断现实发生率。
- **H2：模型价值。** 相同源响应调用预算下，CBC 的**事件边界/时延图**是否比无事件、无图的匹配容量对照更好地排序关键候选？当前未得到支持。不能用胜过 `anchor_copy` 替代对 `anchor_full` 的比较。
- **H3：部署条件。** 事件 guard 是否足以安全决定复用/回退，校准决策是否能控制风险并保有覆盖率？目前没有形式化证书，也没有独立官方反应式闭环证据。

因此：**有研究问题价值；已有的 CBC 网络结构尚未建立“增量创新有效”的证据；不建议立刻扩大到 DSE/TIV 联合大训练。**

## 1. 上传结果中的真实样本、分母和性能

| 指标 | 合成压力 120 场景 | WOMD 初始化 120 场景 |
|---|---:|---:|
| 同意图/运动学匹配代理条件成立的场景 | 120 | 15 |
| 匹配且两个候选在合成参考世界中 Ego 安全 | 100 | 0 |
| 关键 pair（`|ΔC_p| >= 0.2`） | 32 | 0 |
| 旧版单 pair MC 检验认定符号可分辨 | 32 | 0 |
| 所有场景每场景三个非 Ego pair 的参考接触翻转 | 107/360 | 3/360 |
| **限定到匹配场景的参考接触翻转** | **107/360** | **0/45** |
| 是否能评价匹配风险排序的优劣 | 有限、仅合成 | **不能** |

**纠正此前描述错误：**WOMD 的 3 次参考接触翻转发生于全部 360 次比较，**不是**匹配后的 45 次比较。匹配后的 45 次比较为 **0**。这三个 0/1 接触翻转也属于自定义异质响应器的共同种子配对仿真，并非 WOMD 记录了同一个真人对两个未执行动作的潜在结局。

*合成可分辨关键 pair 的错误率*：

| 模型/代价 | 关键风险差符号错误率 | 第三方 union-risk MAE |
|---|---:|---:|
| anchor_copy（唯一 anchor 直接复用） | 100.00% | 0.09957 |
| source（逐候选响应源） | 81.25% | 0.09818 |
| anchor_full（单 anchor + 无图矫正） | 21.875% | 0.10125 |
| anchor_graph（单 anchor + 时延图） | 31.25% | **0.03846** |
| full（逐候选 + 事件特征头） | **6.25%** | 0.08247 |
| no_events（逐候选 + 去显式事件特征） | **6.25%** | 0.08322 |

解读：`anchor_graph` 的 union-risk MAE 很有竞争力，代表可以继续研究**风险校准**，但无法覆盖更重要的**关键候选风险排序错误**；`anchor_full` 排序优于 `anchor_graph`，后者并没有建立图结构的独立价值。`full` 与 `no_events` 完全同分，其成对场景 bootstrap 的符号错误差异 CI 为 `[0,0]`，说明此样本上新增事件显式特征没有产生可检测收益。不过 `no_events` 仍获得源响应器算好的碰撞/几何数据，因此该对照**不能证明制动事件机制全局无用**。

合成数据关键事件集中在场景压力生成机制上；32 个 `pair` 不等于 32 个独立真实道路事件；同一场景 3 个 pair 之间相关。数据集样本应以场景簇（若有可验证的 20s 父片段以父片段簇）计算误差区间，并分开报告自然场景和高风险富集场景，不能汇总成现实风险频率。

## 2. Guard 复用目前并不安全

合成 held-out empirical screen：360 个 pair 比较里 **248** 个被允许复用（68.9%），107 个非 Ego 接触翻转中 **漏报 6** 个（5.6%，名义二项 95% 上界约 10.8%）。该上界还没有处理同一场景内的依赖关系。它既不能作为物理扰动包络证明，也无法保证单次驾驶决策的风险；将复用筛选解释为已认证风险界是错误的。

建议引入**三分支保守路由**：

1. 只有具备可验证 guard 变化上界和 footprint clearance 变化上界、且所有潜在路径均已覆盖时，才允许认证式 Anchor 复用。
2. 边界可疑但完整反应模型足够支持时，运行候选特定反应仿真；把成本计入真实耗时。
3. 观察模型离分布、guard 缺失、车道关系无法确定、参考 MC 符号仍不可辨时，返回 `UNRESOLVED`，不能伪装为低风险。

形式化依据仍以原论文为主：

\[
 \lvert C_{\rm down}^{P_m}(a)-C_{\rm down}^{P_m}(\bar a)\rvert
 \leq P_m(\mathfrak B(a\mid\bar a))
\]

前提是**guard 完备 + 同一结构族内的有效扰动上界**。当前 PyTorch 图网络、经验屏幕和简单的 brake 阈值都不能替代前提。其安全有效性必须独立测量，而不能从神经网络低 MAE 推得。

## 3. WOMD 到底告诉了我们什么？

**这次上传只证明了：**WOMD Scenario 中成功生成了 120 个几何走廊初始状态，但静态的、为合成四车设计的 Early/Late 候选在其中匹配通过率只有 15/120，匹配且双候选 Ego 安全率 0/120。源响应器与参考响应器是在这些初始状态上执行的**自定义结构模型**，而不是对真实驾驶员没执行过的动作取得了观察反事实。

**目前不能从报告推断的现象：**WOMD 上真实紧跟距离分布、急刹发生率、对驾驶延迟的条件响应、实际二次碰撞的频率、地图合法性。此前报告只给出几何筛选和模型条件输出；这些现象需要新增脚本在服务器对规划时刻可见历史执行统计。

现已加入两条**不使用 WOMD future 标签**的预检查：

- `scripts/inspect_womd_context.py`：跟车间距、TTC/THW、初始 OBB 冲突、短历史是否出现急刹、不同假定延迟下的停止裕度、可用地图占比。结果是**预选几何走廊的分布**，不是 WOMD 总体比例。WOMD 标准 1s 历史不能稳健测出发生在窗口之前的长制动反应时延。
- `scripts/cbc_candidate_design.py`：`fixed` 对 `observed_adaptive`，比较同意图匹配通过率、动态舒适条件、常速度名义间隙，不用参考碰撞标签选择候选。**它仍没有真正检验导航路线、车道连接和交通法。**

**研究假设、不是本次数据事实**：短 THW、后车高速闭合、B 触发迟刹、C 反应慢、B 与 C 制动能力差异、桥/弯道感知延迟、异质让行协议、超出两跳的冲突传递，这些可能正是“几何接近但响应模式不同”的高价值来源，应先由历史统计发现候选区域，再由独立闭环模型验证。

独立研究（2025 年的一份自然数据验证预印本）报告 WOMD 对突然减速和小车头时距可能存在低覆盖问题；这是**外部研究结论且尚非本次报告实测**，提醒需要对边界场景采用独立数据来源，不应用 WOMD 的历史分布来宣称所有人类驾驶时延范围。

## 4. CBC 研究路线的建议调整

### 阶段 A：先修候选设计，再谈时延图

从“静态直线四车 + 固定早晚制动时机”改为“全局地图保留 + t<=0 真实历史 + 预定义目标车道和合法路径 + 多个同意图纵向速度时机”。预注册候选差异阈值和任务代价容差；不要根据事后参考 B–C 碰撞来挑选成功的动作。必须同时报告：全部场景分母、可构造匹配分母、几何/法律有效分母、两个候选在**独立参考世界**中都 Ego 安全分母，以及关键风险差达到 MC 分辨率的分母。只有最后一个分母足够大，才谈符号错误率。

### 阶段 B：增加真正可能有用的物理机制输入

使用候选的**实际控制差序列**而不仅是 `pulse_begin/pulse_end/decel`；使用受交通拓扑和遮挡约束的时间有向图，并保证每条信息满足 `t_rx >= t_tx+delay`。加入事件边界的显式距离，例如 B 的可行制动模式 guard 与 C 的候选条件停止裕度。停止裕度可以使用

\[
 m_{C|B}^{\pi}(t)=d_{CB}(t)-\max\!\left\{0, v_C\tau_C+
 \tfrac12 a_C^{\rm pre}\tau_C^2+
 \frac{(v_C+a_C^{\rm pre}\tau_C)_+^2}{2b_C}
 -\frac{v_B^2}{2b_B}\right\},
\]

但**仅在 C 跟驰 B 且制动参数及轨道几何适用时**作为事件风险特征；绝不能当作 2D 碰撞证明。建议采用显式 `valid` 掩码，分别预测 brake-onset、响应时延、交通接触与 union-risk，而不是以单个黑盒 score 包揽所有语义。

可选新增的 **风险差损失**：对经过预定匹配条件的 `(a,b,p)`，用独立参考模型的训练集标签监督 `\widehat\Delta = \widehat C_p(a)-\widehat C_p(b)`，兼顾 Huber 回归与临界风险符号 margin；新版已加入 `--contrast-weight` 作为一项消融，默认 0，不改变历史对照。**尚无证据证明该损失可以提高性能。**

### 阶段 C：优先进行高信息量对照而不是大规模训练

- **图独立贡献**：`anchor_graph` vs `anchor_full`，同一 Anchor、相同训练场景、参数量/搜索预算接近；再做 `anchor_graph_contrast` vs `anchor_graph`。
- **事件独立贡献**：`full` vs `no_events`，并增加真正关闭源反应制动分支的结构消融（未来工作），因为“去事件特征”并未删掉模拟器内部制动影响。
- **复用决策**：以事件 guard/未分辨条件分层报告选择重新仿真比例、反例误放行率、p50/p95/p99 端到端实际延迟；统计同步 CPU/GPU 时间和回退次数。不能以源 rollout 减少 2/3 就断言系统快 2/3。
- **反事实机制**：对 Ego→B→C 预注册真实中介干预，固定 Ego 条件后让 B 处于某一控制模式并**重新模拟 C**；同时提供无 B→C 关联的负对照。普通跨世界轨迹“互换”只是模拟器内部结构证据，不等价人类真实因果确认。
- **独立性**：至少两个在代码/参数上不同的 reference reactor 家族；正式论文需要 Waymax、ReactSim-Bench（或真实互动闭环等价）与 CARLA 等证据组合，而不是训练源和参考标签均属于一个调参合成动力学族。Waymax 官方有 GPU/JAX 多代理仿真能力，但本次代码**未**实现官方完整互操作。

## 5. 停止/继续准则（研究决策而非形式化定理）

**当前：不开始 CBC 大规模训练，也不宣称 DSE/TIV 安全收益。**

1. 阶段0：在冻结的 500–3000 个预选观测场景上候选匹配率、常速度名义安全通过率和历史跟驰/急刹的统计足够稳定；如果几何合格低于 20% 或无有效候选，先修候选/地图而非加深神经网络。
2. 阶段1：在预先选定的独立闭环参考模型上取得至少 **50 个匹配+双 Ego 安全**场景、至少 **30 个风险符号参考可分辨**关键 pair（这是最低工程诊断数，非论文显著性样本量定理），使用场景簇 bootstrap。
3. 阶段2：同预算 `anchor_graph` 减少 `anchor_full` 的关键排序错误；`full` 明显优于 `no_events`，或具备合理“事件过滤 + 回退”收益。需要可信 CI 不跨零并在独立模型族重现，才建议投入 full hybrid guard / calibration。
4. 阶段3：把认证 guard 的物理证明和统计边界筛选**明确分开**。只有在有充分的物理管束、统计漏检校准和真实闭环时间预算后，进入 DSE/TIV 大训练。

## 6. 修订代码和论文的完成度

**已实现并本地验证：**v3 论证门槛、matched/all flip 独立分母、候选失败原因、局部 MC/场景 bootstrap 诊断、WOMD 历史跟驰/制动审计、观测信息限定候选设计、地图坐标归一化保留、可选候选风险差训练、CUDA device 参数、2 GPU 双进程消融脚本、小型报告打包和回归测试。

**尚未实现：** 完整的地图拓扑/法规合法候选、真实场景下多跳 delayed hybrid guard 证书、原论文可验证扰动上界、源与参考真正异构的官方 reactive episodes、DSE 实车/真实执行前缀认证、TIV 终端独立校准。`OBSERVATION_ONLY_ADAPTIVE_V1` 是数据分布诊断器而不是已经合格的生产规划候选器。论文新增探索性实验及损失式均以其实际完成状态表述，不作成功宣称。

完整数值和旧报告新判定见 `CaVER_CBC_v3_evidence_reanalysis.json`。不应把修订后的 `novelty_verdict` 与旧的宽松 `verdict` 混为一谈。
